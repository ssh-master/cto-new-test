# QA Issues Log

## Purpose
Central hub for quality assurance to document test results, capture defects, and coordinate validation work across all tournament phases.

## How to Use
1. Record test sessions under the appropriate phase.
2. Document observed defects with clear reproduction steps, severity, and environment details.
3. Reference related requirements from `todo.md` or completed work from `done.md`.
4. Update resolution status once fixes are verified.
